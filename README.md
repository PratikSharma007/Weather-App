# Weather App 🌤️

A simple and responsive Weather App built using **HTML, CSS, and JavaScript**. It fetches real-time weather information from the OpenWeatherMap API based on the city entered by the user.

## 🚀 Features

- Search weather by city name.
- Display current temperature.
- Show weather conditions and icons.
- Display feels-like temperature.
- Show humidity and wind speed.
- Loading message while fetching data.
- Error handling for invalid cities and API errors.
- Responsive design for mobile and desktop screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- OpenWeatherMap API
- DOM Manipulation

## 📸 Features Overview

The application displays:
- Weather Icon
- Temperature
- Weather Description
- Feels Like Temperature
- Humidity
- Wind Speed

## ⚙️ Setup Instructions

1. Clone this repository:

   ```bash
   git clone https://github.com/PratikSharma007/Weather-App.git
   ```

2. Open the project folder.

3. Get an API key from [OpenWeatherMap](https://openweathermap.org/api).

4. Create a `config.js` file in the project directory:

   ```javascript
   const ApiKey = "b49a2506bad881107a9a6e1d99d5fa48";
   ```

5. Open `index.html` using Live Server.

**Note:** Do not upload your API key to GitHub. Add `config.js` to `.gitignore`. Client-side API keys are still visible to browser users, so this setup is intended for learning purposes.
